# qaroutes

## Обновление базы

Экспортируйте коллекцию Яндекс Карт в CSV и запустите:

```bash
python3 scripts/update_database.py /путь/к/экспорту.csv
```

Скрипт проверяет структуру CSV, обновляет встроенную базу в `index.html`,
сохраняет ручные категории и метро для известных мест и синхронизирует
количество мест в приветствии бота. Для предварительной проверки добавьте
флаг `--dry-run`.

## Проверка подписки

Бот проверяет подписку на `@qaroutes` перед выдачей кнопки и через API
`POST /subscription` при открытии приложения, сборке и замене маршрута.
Бот должен быть администратором канала: иначе Telegram не гарантирует
проверку других пользователей. При ошибке проверки доступ закрыт до повтора.

В Render нужны `BOT_TOKEN`, `WEBAPP_URL` (адрес `index.html`) и
`RENDER_EXTERNAL_URL` (Render задаёт автоматически). Адрес API добавляется
в кнопку автоматически. Старые сообщения без адреса API требуют нового `/start`.
Если в BotFather настроена отдельная кнопка меню приложения, её URL также
должен содержать `?api=https://АДРЕС-СЕРВИСА.onrender.com`.

Страница и встроенная база остаются публичными статическими файлами.
Проверка ограничивает обычное использование интерфейса Telegram, но не является
защитой базы от скачивания или модифицированного клиента.
