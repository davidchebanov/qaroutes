# qaroutes

## Обновление базы

Экспортируйте коллекцию Яндекс Карт в CSV и запустите:

```bash
python3 scripts/update_database.py /путь/к/экспорту.csv
```

Скрипт проверяет структуру CSV, обновляет встроенную базу в `index.html`,
сохраняет ручные категории и метро для известных мест и синхронизирует
количество мест в приветствии бота. Для предварительной проверки добавьте
флаг `--dry-run`.
